 PromptLebanon

A library of ready-to-use AI image prompts, with a preview image for every idea.

 🚀 About the Project

PromptLebanon organizes 1,000+ AI image prompts in one place, making it easy to browse, preview, and copy the prompt you need in one click.

 ✨ Features

- 📚 1,000+ prompts across 23 categories
- 🖼️ Preview images for prompts
- 🔎 Search and filter by category
- 📋 One-click prompt copying
- 🌐 Simple, fast, and user-friendly interface

🛠️ Project Structure

- `index.html` — Main page
- `app.js` — Site logic
- `style.css` — Website styling
- `lebanon_ai_1000_image_prompts_with_previews.json` — Prompt data
- `previews/` — Preview images
- `generate_previews.py` — Preview generation script
- `README-SECURITY.txt` — Security notes
